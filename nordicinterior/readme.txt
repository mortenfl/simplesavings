Lugnt, nordiskt katalogtema för inredning och möbler med WooCommerce externa produkter (affiliate).

== Description ==

Nordic Interior är ett klassiskt PHP-tema för en svensk inredningskatalog. Besökaren hittar möbler efter rum, stil, kategori, material, färg, mått, varumärke och butik och skickas vidare till butiken via produktens affiliatelänk. Se README.md för fullständig dokumentation.

== Installation ==

1. Installera och aktivera WooCommerce 9.6 eller senare.
2. Ladda upp och aktivera temat.
3. Gå till Nordic Interior → Kom igång.
